# ⚡ Gym Logger App

A modern, full-stack workout logging web application built with a **Django REST Framework** backend and a **React** frontend featuring a Glassmorphic UI with animated visuals.

---

## ✨ Features

* **User Authentication:** Token-based login system securing user workout logs.
* **Dynamic Workout Logger:** Dynamically add, edit, or remove exercise rows (sets, reps, weight) for a training session.
* **Real-time Activity List:** Automatically fetches and updates saved workout sessions without full page reloads.
* **Exercise & Muscle Guide:** Interactive side panel with glassmorphism modal popups detailing targeted muscle groups, hypertrophy mechanics, and form tips.
* **Modern UI/UX:** Responsive glassmorphism interface floating over an animated moving gym background.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Axios, CSS3 (Glassmorphism & CSS Animations)
* **Backend:** Django, Django REST Framework, Django CORS Headers
* **Database:** SQLite (Default)
* **Authentication:** Django Token Authentication
